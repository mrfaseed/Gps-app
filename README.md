## About The Project

GPS Map Camera is an Android application designed for anyone looking to embed accurate location-based functionality directly onto photos and images. Ideal for travelers, professionals (construction, real estate, field surveys), and photographers who want seamless geotagging with high precision.

## Key Features

- **GPS Tagging**: Automatically embeds precise location coordinates, altitude, address, date, and time stamps directly onto photos.
- **Customization**: Add notes, hashtags, customized numbering, compass directions, and weather info.
- **Multiple Map Types**: Choose between Normal, Satellite, Terrain, and Hybrid map overlays.
- **Offline Mode**: Capture and tag photos even without an active data connection; updates once reconnected.
- **Photo Management**: Organize photos into dedicated folders for easy project and travel cataloging.
- **High Resolution Support**: Preserves image quality while overlaying clean, readable geotag stamps.
